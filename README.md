# peyto-skills

My personal collection of skills for working with AI agents.

This is a space to experiment with different ways of working, refine what works for me, and build toward my ideal agentic workflow. The skills will evolve as I learn and try new approaches.

## Install / update

```sh
npx -y skills add kma8794/peyto-skills -g -y
```

- `npx -y` — Run the CLI, automatically accepting its download if needed.
- `skills add` — Install or reinstall skills from the source.
- `kma8794/peyto-skills` — The GitHub repository containing the skills.
- `-g` — Install globally for your user, across projects.
- `-y` — Skip the skills installer's confirmation prompts.

## Skills

- [java-coding](java-coding/SKILL.md) — Personal Java coding preferences focused on readability and minimal, meaningful comments.
- [confirm-request](confirm-request/README.md) — Check the agent's understanding of a request before it starts working.
