# confirm-request

Use this skill when you want to check that the agent understands your request before it starts working.

Controlling the agent's understanding is an important part of controlling the work. The first checkpoint comes right after you formulate a task, before anything is done: make sure the agent understood what you meant.

This is also useful with voice input. A spoken request may contain repetition, unfinished thoughts, or transcription errors. The skill turns that input into a clear statement you can review, with uncertainties surfaced for clarification.

Start or end your prompt with **confirm**, **please confirm**, **rephrase**, or **please rephrase**. For example:

> Update the project documentation to explain the setup process. Please confirm.

The agent rephrases your objective and outlines the goal, scope, assumptions, and uncertainties. It does no research or implementation while preparing this response.

Review the restatement, correct anything that is off, and confirm when you are ready for the agent to proceed.
